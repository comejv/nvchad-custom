# NVChad 2.5 custom config
Requires Neovim 0.9.5. To install this config : `git clone git@github.com:comejv/nvchad-custom.git ~/.config/nvim/`
If multiple java installations, make sure to have java 17 for jdtls. Until better solution, if `java` does not run java 17 you can put custom path to java bin in `~/.local/share/nvim/mason/packages/jdtls/bin/jdtls.py`, for example `/lib/jvm/java-17-openjdk-amd64/bin/java`
[Installing openjdk-11 on debian 12](https://ralph.blog.imixs.com/2024/01/24/install-open-jdk-11-on-debian-12-bookworm/)
